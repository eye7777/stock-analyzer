# 個股體檢報告（2012-08-01 ～ 2026-06-22）

> **本報告只做描述，不做顯著性結論，也不主張任何一檔「有某種規律」。** 報告中共有 **689 格**「平均值／差值／迴歸係數」附 95% 信賴區間（比例類指標不計入）。即使每一格的真實值都是零，在 95% 信賴水準下，預期仍約有 **34 格**純屬巧合地排除零；因此任何單一格排除零，都不應解讀為該檔有穩定特性。

由 `python stock_profiles.py report` 產生。驗證期（2026-06-23 起）未進入任何計算。

## 資料與定義

- **期間**：統計日為 2012-08-01 ～ 2026-06-22 的交易日。ATR14 與 60 日標準差的暖身期使用 2012-01-01 起的股價；往後看的報酬窗口超出 2026-06-22 者不計。個股快取經 `HistoryStore.query(as_of=2026-06-22)` 截斷；加權指數與美股只下載到 2026-06-22。
- **6669**：2019-04-01 以前的股價在所有面向都不使用（沿用 backtest 的資料不可信期間）。
- **價格**：報酬、ATR、跳空、除權息走勢一律用還原價（`backtest.adjusted_prices`，含股利再投入）；漲跌停用原始價。
- **信賴區間**：95% CI 為 (股票, 年月) 叢集 bootstrap（2000 次）。

**1. 波動特性**
- ATR% = ATR14（真實區間的 14 日簡單平均，同 `sa.calc_atr`）÷ 收盤；各年取中位數。日報酬標準差為還原收盤對收盤。
- 開盤跳空：開盤 ÷ 前一日收盤 − 1，≥ +3%（上）或 ≤ −3%（下），分開計頻率。
- 漲跌停：參考價 = 前一日原始收盤；除權息日改用 `reference_price`。限制 2015-06-01 以前 ±7%、之後 ±10%，依升降單位向內取整。「收盤」＝收盤價等於漲（跌）停價；「觸及」＝盤中最高（低）價等於漲（跌）停價。驗算：開發期 185 個除權息日，自行計算的漲跌停價與 FinMind（`max_price`／`min_price`）不一致 7 筆，類型 權 4 筆、除權 2 筆、權息 1 筆；其中漲停價不一致 0 筆、跌停價不一致 7 筆（這幾天沿用自行計算的價格，未另外修正）。
- 先碰到哪個價位（基準，不限訊號日）：每個交易日 D 以 D 收盤與 D 當日 ATR 為基準，看 D+1 ～ D+19 的最高／最低價，比較先碰到 +2×ATR（或 +3×ATR）還是 −1.5×ATR；同一天兩者都碰到另列「同日」，19 日內都沒碰到列「未碰到」。窗口不足 19 日的日子不計。

**2. 大漲大跌之後**
- 標準化報酬 = 當日報酬 ÷ 前 60 個交易日（不含當日）日報酬標準差；前 60 日資料不足的日子不列入。每檔取自己開發期標準化報酬的前 5%（大漲日）與後 5%（大跌日）。
- 之後 k 日報酬 = D 收盤 → D+k 收盤（k = 1, 5, 10），與該股開發期全部交易日的平均比較；差值 CI 以同一次叢集重抽計算子集與全體的平均。

**3. 事件前後**
- 月營收年增率 = 當月營收 ÷ 去年同月營收 − 1。可取得日沿用回測規則（M 月營收於次月 10 日之後、即 11 日起第一個交易日可用）；20 日報酬 = 可取得日收盤 → 20 個交易日後收盤。超額報酬 = 個股報酬 − 加權指數同期報酬。每檔依自己的年增率分三等分（低／中／高）。
- 除權息：只分析現金股利（`stock_or_cache_dividend` 為「息」或「除息」），以除息日為第 0 天，第 k 天的累積報酬 = 第 −6 天收盤 → 第 k 天收盤（還原價，已扣除除息缺口）。含股票股利的事件（權、權息、除權、除權息）只列筆數。減資：`TaiwanStockDividendResult` 的事件類型只有息／除息／權／權息／除權／除權息，沒有減資類別；本報告未另外查找減資事件。
- 法說會：本機快取沒有日期資料，依指示未向 FinMind 試探，**本面向略過**。

**4. 連動**
- 加權指數：`TaiwanStockPrice` 的 TAIEX（價格指數，不含股息，對日報酬影響很小）。beta = 個股日報酬對指數日報酬的 OLS 斜率；分年列點估計，全期附 CI。
- 美股（^SOX, NVDA, ^GSPC，`USStockPrice` 的 `Adj_Close`）：台股第 D 日（前一個交易日為 P）對應美股日期 P ≤ u < D 的各場（即台股 D 日開盤前已收盤的美股），休市期間多場連乘；這段期間美股沒有開盤的日子不列入。台股指標分「收盤對收盤」與「開盤跳空」（開盤 ÷ P 收盤 − 1），列相關係數（附 CI）與斜率。

**5. 系統適配**
- 主表：基準回測 `trades_2012-08-01_2026-06-22.csv` 的不重疊交易（全期、無閘門＝現行系統真實行為、stop_first），依訊號日拆成 2024-01-01 前／後。附表：每個推薦訊號各自獨立進場（`backtest.build_outcomes`，已成交、完整 T+19 窗口），交易會重疊。
- 勝率 = ret_net > 0 的比例；期望值 = 平均 ret_net（已扣成本）；R 倍數 = ret_net ÷ 進場時停損距離（同 risk_factors：停損價換算到還原價基準，相對成交價；距離 ≤ 0 者排除，列於「R 排除」）；進場當日停損 = 出場原因為 stop_T0 的比例（stop_first 情境下 T+0 觸及停損即全數出場）。出場原因為最後一筆出場的原因（目標1 出半不另列）。
